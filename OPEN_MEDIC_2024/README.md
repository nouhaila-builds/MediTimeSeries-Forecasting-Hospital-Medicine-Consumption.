1. Open Medic — base complète sur [data.gouv.fr](https://www.data.gouv.fr/fr/datasets/open-medic-base-complete-sur-les-depenses-de-medicaments-interregimes/)
2. Placez le CSV ici : `OPEN_MEDIC_2024/OPEN_MEDIC_2024.CSV`
